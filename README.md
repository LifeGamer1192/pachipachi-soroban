# ぱちぱち そろばん

ちいさな子（4〜6さい）のための、指で玉を動かすそろばんです。iPad・スマホ・PC のブラウザで遊べます。

**あそぶ**: https://lifegamer1192.github.io/pachipachi-soroban/

## できること

- **じゆうに さわる**：玉を指でつまんで上下に動かす。玉の無い所に指を置けば、指で玉を押せる。軽くたたくと、その玉まで一気に動く。梁を横になぞると、5玉が払われる（ごはさん）。
- **指2本で同時に**：5玉と1玉をいっしょに動かす（4 → 5 など）、ちがう桁を同時に動かす。
- **かずを つくろう**：お題の数を、そろばんで作る。
- **いくつかな？**：そろばんに出た数を、3つの中から選ぶ。
- **たしざん**：まず1つ目の数を置き、2つ目の数を足す。
- ヒント（動かす玉が光る）、読み上げ（端末の音声合成）、花まる。

## こじんの じょうほう

名前などの入力はありません。どこにも送信しません。ブラウザの中に残すのは、設定と花まるの数だけです。外部のフォント・解析・広告は読み込みません。

## 絵と音

そろばんの絵と、玉の音・効果音はプログラムで作っています。動物・果物・背景の絵は AI で生成したものです。

このリポジトリは公開用のビルド結果です。
